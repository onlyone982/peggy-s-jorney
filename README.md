# peggy's journey

크롬 공룡 게임 방식의 펭귄 러너 웹 게임입니다. 펭귄 페기가 바다표범, 갈매기, 눈사람을 피해 달리고 생선을 모읍니다.

## 실행

- VS Code에서 폴더를 열고 **Live Server** 확장으로 `index.html`을 실행하는 방법을 권장합니다.
- 터미널에서는 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 열면 됩니다.
- `index.html`을 더블클릭해서 열어도 이미지는 보이고 효과음도 나옵니다. 다만 일부 브라우저에서는 소리가 조금 늦게 날 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 스페이스 / ↑ / 화면 탭 | 점프 (게임 시작, 다시 시작도 같음) |
| ↓ (누르고 있기) | 슬라이드 |

## 폴더 구조

```
index.html        페이지 뼈대
css/style.css     화면 스타일, 게임오버 광고 버튼 모양
js/game.js        게임 전체 코드 (맨 위 CFG에서 속도·크기·간격을 조절)
assets/img/       스프라이트와 배경 이미지
assets/sfx/       효과음
```

## 자주 만지는 곳 (`js/game.js`)

- `CFG` 맨 위 설정: 게임 속도, 낮밤 전환 간격과 시간, 갈매기 크기, 구름 개수와 속도, 생선 간격
- `GULL_BOTTOM`: 갈매기 3단계 높이 (바닥 / 서 있는 펭귄 머리 / 하늘)
- `AD_URL`, `AD_TXT`: 게임오버 때 나오는 버튼의 연결 주소와 문구
- 바다표범 충돌 범위: `upd()` 안의 `o.k==='l'` 부분 (몸통 가운데 절반만 닿으면 게임오버)

## 테스트용 도구

주소 끝에 `#debug`를 붙이면(`http://localhost:8000/#debug`) 브라우저 콘솔에서 다음을 쓸 수 있습니다.

```js
__dbg.setDist(499)     // 점수를 499로 바꿔서 곧바로 밤 전환 보기
__dbg.put('g', 1, 100) // 갈매기(g) 중간 높이(1)를 x=100에 놓기. 'l' 바다표범, 's' 눈사람
__dbg.god(true)        // 죽지 않기
__dbg.state()          // 현재 상태 보기
```

## 스프라이트 규칙

- 달리기: `penguin_01`, `penguin_02`를 번갈아 재생
- 점프: `penguin_03`부터 `penguin_11`까지 순서대로 재생
- 바다표범: `sealion_1`, `sealion_2`를 GIF처럼 번갈아 재생 (좌우 반전한 상태로 저장되어 있음)
- 갈매기: `gull_1`~`gull_6` 반복 재생
